# lekhascan-privacy

Former home of LekhaScan's public privacy policy.

The policy now lives at
<https://dabobrotosarkar.com/lekhascan/privacy>, served by the portfolio site
(`my-ai-portfolio`, page `frontend/src/app/pages/lekhascan/privacy-en.component.ts`).

This repository keeps a redirect at the old address, because links to it are
still in circulation — the Play listing, the Data safety form, AdMob's consent
message and anyone's bookmarks. **Keep it published**; edits to the policy go to
the portfolio site and to the app's own copies in
`app/src/main/assets/privacy_policy_en.html` and `_bn.html`.
